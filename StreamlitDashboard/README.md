# 🏠 Ames Housing Market Analysis

An interactive dashboard exploring house prices in Ames, Iowa.

## 🔗 Live Demo
[View Dashboard](https://data-analytics-portfolio-qhshbtfcz2efcnxq4ffgzs.streamlit.app/)

## 📊 Key Findings
- Overall quality is the strongest price predictor (correlation: 0.79)
- Neighbourhood alone accounts for $227k price difference (NridgHt vs MeadowV)
- House prices peaked in 2007 before declining due to the 2008 financial crisis

## 🛠 Tools Used
- Python, Pandas, Plotly, Streamlit

## 📁 Dataset
- [Kaggle House Prices](https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques)

## 🚀 How to Run
pip install -r requirements.txt
streamlit run App.py
